GitHub

Hosts your Git repositories and the pull requests around them.

GitHub is where Git repositories live online. It adds pull requests for review, issues for tracking work and Actions for automation.

What you use it for

  • Remote backup and sharing of code
  • Pull request review
  • Issues and project tracking

You push a branch, open a pull request, and reviewers or automated checks look at the diff. Required checks can block a merge until tests pass. Merging updates the main branch, which can trigger a deployment.

Pairs well with

  • Git
  • GitHub Actions
  • Vercel

Open and merge a pull request from the terminal

Shell
gh pr create --fillgh pr checksgh pr merge --merge

gh is GitHub's command-line tool.
