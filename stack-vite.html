Vite

A very fast dev server and bundler for modern frontends.

Vite is a build tool that starts a development server almost instantly and bundles your app for production. It is a common starting point for React and other single-page apps.

What you use it for

  • Local development with instant updates
  • Production builds that are minified and split into chunks
  • Plugins for frameworks, TypeScript and CSS

In development Vite serves your source files as native ES modules, so the browser loads only what a page imports and a saved change swaps in without a full reload. For production it bundles and optimizes everything into a few static files.

Pairs well with

  • React
  • Vitest
  • TypeScript

Create and run a project

Shell
npm create vite@latest my-app -- --template reactcd my-appnpm installnpm run dev

The last command prints a local address and reloads on every save.
