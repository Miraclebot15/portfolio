Testing and Quality

Playwright

Automates real browsers to test how a site actually behaves.

Playwright drives Chromium, Firefox and WebKit from code. It can click, type, wait for elements and take screenshots, so you can test a site the way a person uses it.

What you use it for

  • End-to-end tests
  • Responsive and accessibility checks
  • Screenshots and scraping

A script launches a browser, opens a page and uses locators to find elements. Actions wait automatically until an element is ready, which avoids flaky timing code. You can run many viewport sizes and capture console errors in the same run.

Pairs well with

  • Vitest
  • GitHub Actions

A phone-sized smoke test

Python
from playwright.sync_api import sync_playwright​with sync_playwright() as p:    browser = p.chromium.launch()    page = browser.new_page(viewport={"width": 390, "height": 844})    page.goto("https://example.com")    assert page.title() != ""    page.screenshot(path="home-390.png")    browser.close()

Open, assert, capture: the same loop works across every page and screen size.
