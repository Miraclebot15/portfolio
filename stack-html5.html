HTML5

The structure of every page: headings, links, forms and media.

HTML is the markup that gives a page its structure and meaning. HTML5 added semantic elements such as header, main, nav and article, plus native audio, video, canvas and form controls.

What you use it for

  • Page structure and headings
  • Links, forms and buttons that work without scripts
  • Accessibility through correct semantics

The browser reads your tags and builds a tree called the DOM. CSS styles that tree and JavaScript changes it. Using the right element, such as a real button instead of a clickable div, gives you keyboard support and screen reader behavior for free.

Pairs well with

  • CSS
  • JavaScript

An accessible form field

HTML
<form action="/subscribe" method="post">  <label for="email">Email</label>  <input id="email" name="email" type="email" required>  <button type="submit">Subscribe</button></form>

The label, the type and required give validation and assistive support with no JavaScript.
