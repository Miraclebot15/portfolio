Node.js

Runs JavaScript outside the browser, for servers and tooling.

Node.js is a runtime that executes JavaScript on your machine or a server using the V8 engine. It lets one language cover both frontend and backend, and it powers most JavaScript build tools.

What you use it for

  • HTTP servers and APIs
  • Command-line tools and scripts
  • Build tooling for frontend projects

Node runs your script on a single-threaded event loop and hands slow work such as file and network access to the system, so thousands of connections can wait cheaply. npm installs packages, and modules load with import or require.

Pairs well with

  • Express
  • JavaScript
  • Zod

A tiny HTTP server with no dependencies

JavaScript
import http from "node:http";​http.createServer((req, res) => {  res.setHeader("content-type", "application/json");  res.end(JSON.stringify({ ok: true, path: req.url }));}).listen(3000);

Save it as server.mjs, run node server.mjs and open localhost:3000.
