Data and Auth

SQLite

A full SQL database in a single file, with nothing to run.

SQLite is a database engine that lives inside your application and stores everything in one file. There is no separate server, which makes it ideal for small apps, local tools and prototypes.

What you use it for

  • Local and embedded data
  • Prototypes and small services
  • Test databases

Your program opens the file and reads and writes it directly through a library. SQLite supports most of SQL, transactions and indexes. Backups are a file copy, though heavy concurrent writing from many servers is where a server database fits better.

Pairs well with

  • PostgreSQL
  • Python
  • FastAPI

Create, insert and count

Python
import sqlite3​db = sqlite3.connect("app.db")db.execute("CREATE TABLE IF NOT EXISTS notes (id INTEGER PRIMARY KEY, text TEXT)")db.execute("INSERT INTO notes (text) VALUES (?)", ("hello",))db.commit()print(db.execute("SELECT count(*) FROM notes").fetchone())

The ? placeholder passes values safely, which prevents SQL injection.
