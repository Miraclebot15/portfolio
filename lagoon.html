About

Lagoon aims to combine several kinds of digital interaction in one experience instead of spreading them across separate apps: direct and group messaging, stories, short video and communities. Its backend API is deployed and provides the foundation, and the full application is in development.

A product that combines messaging, ephemeral content and media is mostly a distributed-systems problem, so the design concerns are delivery semantics, content lifetime, fan-out cost and the media path.

What it’s for

  • Direct and group messaging.
  • Stories and temporary updates.
  • Short-form video.
  • Communities and shared spaces.
  • A deployed backend API, monitored by a live status check on this site.

Engineering concerns

Design concerns for a combined messaging, stories and video platform.

  1. Messaging needs ordering, delivery state and idempotent sends, because networks drop and repeat messages.

  2. Stories and temporary updates are data with an expiry. The system must enforce that expiry, not only hide content in the client.

  3. A group or community message multiplies per recipient. When and where that multiplication happens drives cost and latency.

  4. Short video needs upload, processing and delivery stages, each with its own failure modes and retry behavior.

  5. The deployed API is covered by an availability check, so its state is visible instead of assumed.
